# 폴드투언폴드 체험

동아사이언스 기사 「성가신 폴더블폰 화면 반사, 엿보기 막는 기술로 탈바꿈」(2026.11.10)에 나온
**폴드투언폴드(Fold2Unfold)** 원리를 직접 만져 보는 웹앱입니다. 파일 하나(`index.html`)로 동작하고
빌드 과정과 외부 라이브러리가 없습니다.

- 기사: https://www.dongascience.com/ko/news/80800
- 논문 DOI: https://doi.org/10.1145/3830398.3830569

## 실행

```bash
cd fold2unfold
python3 -m http.server 8080   # 그리고 브라우저에서 http://localhost:8080
```

`index.html`을 브라우저로 바로 열어도 됩니다.

## Android 앱(APK)

`android/`에 `index.html`을 WebView로 감싸는 얇은 Android 프로젝트가 있습니다. 웹 소스는 `index.html` 한 벌만
유지하고, 빌드할 때 APK의 assets로 복사합니다.

```bash
cd android
export ANDROID_HOME=/path/to/android-sdk   # platforms;android-35, build-tools;35.0.0 필요
./gradlew assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

- 외부 라이브러리가 없고 인터넷 권한도 요청하지 않습니다. 화면은 모두 기기 안에서 그려집니다.
  외부 링크(출처)는 브라우저 앱으로 넘깁니다.
- 실기기 모드를 열면 시스템 바를 숨기고 화면을 켜 둡니다. 뒤로 가기는 설정창, 실기기 모드 순으로 닫습니다.
- 폴더블을 접고 펼쳐도 액티비티를 다시 만들지 않아서 페이지 상태가 유지됩니다.
- minSdk 26(Android 8.0), targetSdk 34.
- `assembleDebug`는 Android 디버그 키로 서명합니다. 직접 설치(사이드로딩)해서 써 보는 용도입니다.
  스토어 배포나 업데이트 배포에는 본인 키스토어로 서명한 release 빌드가 필요합니다. 키스토어는 저장소에 넣지 마세요.

## 구성

| 화면 | 내용 |
| --- | --- |
| 체험 | "나"와 "옆에서 훔쳐보는 사람"의 시점을 나란히 보여 줍니다. 접힘 각도, 머리 위치, 훔쳐보는 각도를 바꿔 볼 수 있습니다. |
| 실기기 모드 | 반쯤 접은 폴더블폰에서 위 화면과 아래 화면을 각각 전체 화면으로 띄웁니다. (실험 기능) |
| 원리와 한계 | 기사 요약, 기사에 나온 수치, 이 앱의 한계 |

## 동작 방식

1. **기하**: 경첩을 x축으로 두고, 접힘 각도 φ와 눈 위치로 "위 화면에 비친 아래 화면"의 경로를 거울 반사 공식으로
   계산합니다. 순방향(위 화면 → 아래 화면)과 역방향(아래 화면 → 위 화면) 매핑을 둘 다 구현했고, 서로 역이 되는지
   확인했습니다.
2. **이미지 쪼개기**: 위 화면 이미지는 무작위 알갱이 무늬입니다. 아래 화면 이미지는 숫자 안쪽에서는 위 화면과 같은
   무늬, 바깥쪽에서는 뒤집은 무늬입니다. 두 장은 각각 숫자와 통계적으로 무관합니다.
3. **미리 찌그러뜨리기**: 아래 화면 이미지는 눈 위치에 맞춰 반사 경로의 역변환으로 미리 왜곡해서 그립니다.
   정확히 겹치면 바깥쪽은 고른 회색, 숫자 안쪽은 알갱이로 반짝여서 숫자가 읽힙니다.
4. **판독도**: 숫자 안쪽과 바깥쪽의 밝기 흩어짐 차이로 낸 지표입니다. 이 앱 방식 기준의 값입니다.

## 한계

- 기사에 나온 원리만 보고 만든 체험용 시뮬레이터입니다. 논문의 실제 알고리즘이 아니고, 기사의 7.5°나 0.65개 같은
  수치를 재현한 것도 아닙니다.
- 앞면 카메라 눈 추적은 없습니다. 머리 위치는 슬라이더와 버튼으로 입력합니다.
- 웹은 접힘 각도를 읽을 수 없어 직접 맞춰야 합니다. 실기기 모드는 실제 폴더블폰에서 확인하지 못했습니다.
